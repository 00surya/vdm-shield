How security checks continue

During a quiet scene, pose and visible weapon checks still run once every second, and depth runs once every ten seconds. Motion immediately restores full processing. These figures measure model work, not electricity, carbon emissions, or detection accuracy.

Advanced: processing speed and FPS

Input FPS is the video arriving from the camera. Analysis FPS is the measured pose/motion processing rate. Target FPS is the requested analysis rate, not a guarantee.

Depth and object checks run separately; their “Ready” status does not mean they process every frame. The browser display rate can also differ.

If analysis stays below target, test with fewer active cameras or investigate device performance. You can choose a lower target to reduce requested work, but it does not make the hardware faster and may miss brief activity.

Set a whole number from 1–60 and select Save FPS. Changes apply without restarting the camera and persist across restarts. Wait for fresh measurements after saving. Test representative footage before choosing a deployment rate.

“On pace” means at least 90% of the lower of input FPS and target FPS. It measures speed, not detection accuracy.
